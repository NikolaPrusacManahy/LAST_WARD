# Last Ward

First-person horror prototype: Vite + React + TypeScript + Three.js. Desktop only (keyboard + mouse).

```powershell
npm install
npm run dev          # http://localhost:5173 (START_GAME.bat in the parent folder does this)
npm run verify:quick # typecheck + rule tests
npm run verify       # + production build
```

Controls: WASD move · mouse look · Shift run · C crouch · F flashlight · E interact · Esc pause.

See `../CLAUDE.md`, `../DEVELOPMENT.md` and `../HANDOVER.md`.
