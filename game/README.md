# Last Ward

First-person horror prototype: Vite + React + TypeScript + Three.js. Desktop only (keyboard + mouse).

```powershell
npm install
npm run dev          # http://localhost:5173 (START_GAME.bat in the parent folder does this)
npm run verify:quick # typecheck + rule tests
npm run verify       # + production build
```

Controls: WASD move, mouse look, Shift run, Ctrl crouch, right click flashlight, left click collect / interact, Q look back while running, Esc pause.

See `../README.md` for the full overview, plus `../DEVELOPMENT.md` and `../HANDOVER.md`.
