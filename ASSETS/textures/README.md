# Textures

Raw textures (PNG/JPG). They replace the canvas-drawn ones in `game/src/engine/textures.ts`.
Useful names: `wall_*.png`, `floor_*.png`, `ceiling_*.png`, `decal_blood_*.png`, `note_paper.png`.
PBR sets (albedo / normal / roughness) are welcome — keep each set's files together with the same prefix.
