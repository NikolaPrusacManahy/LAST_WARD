# Audio

Raw sounds (WAV/MP3/OGG). They replace the synthesised sounds in `game/src/audio/audio.ts` one by one.
Useful names: `footstep_*.wav`, `enemy_step_*.wav`, `enemy_breath.wav`, `scream.wav`, `stinger.wav`,
`ambience_drone.wav`, `generator_start.wav`, `generator_hum.wav`, `door_open.wav`, `pickup.wav`, `paper.wav`, `flashlight_click.wav`.
