# First-person arms

Put first-person arms here (ideally already holding a flashlight).

| File | Used when |
|---|---|
| `arms.glb` / `arms.fbx` | The arms (with skin) |
| `arms_idle` | Standing — slight breathing sway |
| `arms_walk` | Walking |
| `arms_run` | Sprinting |
| `arms_raise` / `arms_lower` | Flashlight on / off (F) (optional) |
| `arms_pickup` | Picking up an item (E) (optional) |

If the arms don't hold a flashlight, that's fine — the flashlight can be attached to the hand bone in code.
